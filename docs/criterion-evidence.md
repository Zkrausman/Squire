# Opt-in criterion proof (SQF05 A3)

A3 builds on the shipped A2 producer and passive inspector. Owner-supplied `execution.version: 2` tickets freeze criterion mappings before implementation; existing planner output and version-1 tickets remain version 1 and narrative-only. Each version-2 checklist item adds `evidenceKinds: ["configured-check"]` and `checks: ["configured-name"]`. Execution adds `checkOwnership` for every configured check: `{check, kind, path, sha256}`. This is the first supported proof kind; browser, native, screenshot and human requirements remain incompatible with commands/mocks and block before implementation spend.

A `trusted-inline-node` binding uses `path: null` and the SHA-256 returned by `digest(checkDefinition)` for frozen `node -e CODE` or `node --input-type=module -e CODE` argv. A `trusted-node-file` binding names the exact absolute Node script argv path outside the managed project root and the file's raw SHA-256. The controller rejects aliases, candidate-relative/controlled scripts, nonregular or oversized files and changed bytes; definitions are checked before dispatch and again when resolving observations. Trusted files are bounded to 1 MiB. These are owner-reviewed definitions, not automatic guarantees of oracle quality, immutable imported dependencies or hostile same-user isolation. Required oracle dependencies must remain independently controlled by the owner.

Passing configured checks produce ordinary A2 immutable manifests. Version-2 proof uses only verified current candidate/tree, contract/correction, check-policy, artifact and registered-process identities. Each admissible observation is identified as `MANIFEST_UUID:CHECK_INDEX`. Failed, NOTRUN, missing, omitted, altered or incompatible observations cannot satisfy a criterion. Fresh version-2 review adds `version: 2` and `observationIds` on each checklist result; persuasive prose or unknown/unmapped IDs cannot pass. The runtime receives the schema from the controller's frozen review contract. The same implementation-session rejection remains in force.

The controller re-resolves proof before review, after review and through publication/CI/merge. Repairs, normalization and candidate/base changes invalidate the current projection; immutable historical observations remain retained. Authorized correction criteria must carry the same version-2 mapping fields and use the frozen ownership definitions. Delivery retains existing exact-head checks, review, CI, ancestry/tree and postmerge gates.

Postmerge checks reuse A2 under a separate `postmerge-verification` binding for the exact verified merge head/tree. Candidate and delivered references remain distinct. The existing merge tree/ancestry proof establishes their allowed relationship; every required configured check is rerun and its immutable delivered observations resolve before `acceptedCriteria` is projected. That projection records reviewer job/session, candidate/delivered heads, contract/check policy and delivered IDs. It proves only the mapped configured-command criteria at these identities, not other evidence kinds or general autonomous delivery.

A2's checkpoint cross-link remains a separate diagnostic. A rebase or squash can leave an older row; command proof independently verifies current check identities, artifacts and process links while retaining that stale/unresolved diagnostic. It never relabels the row current or grants adoption, replay, fence release, refunds or descendant settlement. The A2 inspector itself remains diagnostic-only with `acceptance: not_evaluated`.

Linux is the supported platform. Offline tests exercise the real controller with fixture runtimes and local delivery, negative artifact/identity/reference cases and mocked schema production; they make no live-model or sandbox-boundary claim. SQF02's unresolved exact-policy mapping, benchmark holds and existing process-tree limits remain unchanged. Shipment requires independent exact-head review, the complete Linux suite, ordinary draft PR/CI/guarded merge and remote/postmerge verification.

Reuse lesson: bind retained observations to the current admitted contract and consume them at the actual gate. Preserve legacy fields and historical negative receipts instead of deriving acceptance from prose or cached projections. The earlier A2 rebind and its postmerge proof remain separate source evidence.
