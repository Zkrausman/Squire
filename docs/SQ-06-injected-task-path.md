# SQ-06: fake task path across accepted interfaces

`test/injected-task-path.test.mjs` is an integration test fixture, not a runtime entrypoint. It joins the existing AGY preparation, startup ownership/adoption, known-custody coordinator, output collector, artifact verifier and lifecycle/JobRecord validators using only explicitly supplied synthetic ports. No new exported runner or wire mapping is introduced.

The happy path prepares an explicit synthetic AGY model/effort/executable with the original owner deadline and `runtime_admitted=false`. A test caller models one possible dispatch and supplies the fake matching custody ACK. The genuine retained startup operation is adopted into the existing session without calling the fake manager start method a second time. A manual in-memory clock/scheduler and explicit manager-event producer drive the known-custody coordinator; they are not selected native implementations.

The output collector receives explicit byte chunks, EOFs and raw wrapper observations. Its metadata remains separate from native exit, task correctness and settlement. The lifecycle receives a separate complete synthetic admission assertion; the fixture does not derive workspace/history fence or process allocation evidence from an ACK. Parsed provider SUCCESS cannot substitute for a required artifact, a zero native exit or descendant settlement.

The artifact verifier is always passed an explicit in-memory filesystem port. It reads synthetic `abc` bytes and hashes them through the real verifier logic; the expected SHA-256 and byte count are asserted independently. No default filesystem port, actual directory, native process, pipe, bus, provider or historical benchmark fixture is used by these integration tests. A complete matching synthetic empty-descendant observation is required before the fixture advances settlement. The test caller supplies a complete explicit final record to the existing validator, then elects local workspace release. Coordinator return, EOF and final record validation each remain separate facts.

Negative paths cover provider SUCCESS with missing artifacts, independently observed exit 7, capacity advice requiring explicit owner cancellation, original deadline during an injected artifact read, loss of manager custody after successful verification, absent raw wall duration, preparation refusal and passive provider ERROR. UNKNOWN settlement is a failure/cancellation representation, never positive cleanup proof. A null raw wall duration withholds the final record: the fixture does not borrow provider elapsed duration, synthesize zero or widen the existing wire type. No production null-counter/model mapping is selected here; explicit complete fixture metrics use the existing schema, and absent metrics remain UNKNOWN through existing validation.

These tests prove composition under their supplied observations only. They do not establish real admission, dispatch, effective Credits Off, permissions, native drain, full descendant custody, host lifetime, scheduling liveness, persistent records or benchmark readiness. Native startup remains disabled. The production glue contract is requested from Lore for precise admission/provenance/record and verification-cancellation boundaries; that message submission is currently unconfirmed. The staged qualification plan remains in Lore's lane.
