# Comparison trace report scaffold

Companion to the [trace reportability decision](../research/trace-reportability-contract.md). This is an empty reporting scaffold, not a new benchmark protocol, rubric, machine schema or completed result. Preserve the established frozen pair, input, limits, artifact-selection and independent-grading requirements. A blank scaffold does not authorize data acquisition, entry of actual results or distribution of an actual report; use the applicable evidence, execution and destination approvals.

## Acceptance and reportable conclusion — UNMEASURED

- Independent actual application observations: UNMEASURED. Reference the accepted frozen grading contract without including protected grader instructions or contents.
- Calibration status, if any: UNOBSERVED; an unscored control calibration and its `accepted` field do not establish benchmark acceptance.
- Complete all-assignment resource total: NOT ESTABLISHED.
- Cost per accepted delivery / savings comparison: UNDEFINED OR UNESTABLISHED until the protocol's numerator, denominator and completeness requirements are met. Zero accepted deliveries does not yield a finite cost-per-accepted-delivery ratio.
- Current reportable conclusion: NO RUN OR ACCEPTANCE RESULT SUPPLIED BY THIS SCAFFOLD.

Keep raw events, job arrays, paths and sensitive evidence in their authorized storage. Use authorized evidence references in any destination-approved derivative; this scaffold does not sanitize actual data. Missing fields remain unknown, never silently dropped. An independent assessor must verify evidence coverage and that the conclusion follows from the evidence before treating a populated report as accepted.
