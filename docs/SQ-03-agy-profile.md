# SQ-03: AGY one-shot JSON source profile

This profile prepares data only. Every `prepareAgyArgv(spec, limits)` result has `runtime_admitted: false`; success is `PREPARED_NOT_EXECUTABLE`. No launcher, shell, PATH resolution, environment access, credential discovery, timer, provider call or custody action exists here. The administrative compatibility label must exactly equal CLI `1.4.3`. It proves neither installed binary identity nor authentication; mismatch rejects without an update or fallback.

The caller supplies a full existing JobSpec, separate low/medium/high effort, explicit executable reference, prompt bytes, original owner `task_deadline_ms` and `observed_now_ms`, plus a closed policy snapshot. The JobSpec is validated without alteration, including required artifacts and optional fenced history. No model, budget or effort defaults exist. The policy snapshot's model/effort allowlists and quota boolean are caller assertions only. `QUOTA_EXHAUSTED` describes supplied policy, not observed account state; a true value does not admit execution.

`AGY_BYTE_LIMITS` fixes prompt 1–32768 bytes, stdout 2–1048576 bytes, and discarded stderr count at most 65536 bytes, inclusive. Every supplied limits object must match all three exact caps; the profile decoder requires `max_response_bytes: 1048576`. `validateAgyPrompt(bytes, limits)` accepts only Uint8Array and counts actual bytes before fatal UTF-8 decoding. Empty, oversized, BOM, NUL and invalid surrogate encodings reject. Literal backslash-u prompt characters are plain text; valid non-BMP scalars remain intact. Prompt contents are retained only in the prepared argv value, never in metadata or diagnostics; callers must not log or persist the plan.

The argv is exactly executable, `--prompt`, one prompt argument, `--output-format`, `json`, `--model`, original requested model, `--effort`, caller effort, `--print-timeout`, whole-minute duration, `--sandbox`, `--disable-slash-commands`. The last two flags stand alone. Unknown input fields and arbitrary flags are rejected. Validating argument data proves neither OS argument execability nor effective CLI sandbox enforcement.

Remaining time is the original deadline minus the explicit observed time. The response wait is `floor((remaining_ms - 15000) / 60000)` minutes. Below 75000ms preparation returns `BUDGET_INSUFFICIENT_FOR_PROFILE`, which does not mean task TIMEOUT. Preparation cannot reserve or reset a budget; the custody owner must revalidate at any eventual dispatch. One CLI root does not imply one model/tool step; max_steps descendant enforcement is unknown.

The profile-scoped `decodeAgyJson(input)` adds fixed caps, BOM/NUL and unpaired JSON surrogate rejection to the [general metadata decoder](SQ-03-provider-metadata.md). It leaves that general module unchanged. Duplicate decoded keys and all trailing malformed content reject. A syntactically valid `{}` retains the base `UNRECOGNIZED_STATUS` diagnostic and never means provider success or task delivery. Raw exit, signal, elapsed wall duration, provider status and task outcome remain separate; task outcome is always unevaluated. No whole response/error/tool text enters output.

`isAgyStderrByteCountWithinLimit(count, limits)` is a pure nonnegative-safe-integer count check; it accepts no content and does not collect or drain anything. `AGY_CHILD_ENV_DELETIONS` is immutable policy data naming GEMINI_API_KEY, GOOGLE_API_KEY and GOOGLE_GEMINI_BASE_URL for a future cloned child vector. Nothing reads or mutates host environment. These named deletions do not prove exclusion of API fallback through files or other routes.
