# SQ-06: injected source task coordinator

`createInjectedTaskCoordinator(options)` composes the accepted AGY profile, retained startup ownership/adoption, known-custody manager bridge/deadline driver, output collector, physical artifact verifier and lifecycle/JobRecord validators. It has no dispatch function, native defaults, stream pump, host configuration, provider task or benchmark. Its plan always has `runtime_admitted=false`; every task snapshot reports `NOT_ESTABLISHED_BY_SOURCE` runtime qualification.

Configuration is closed and explicit: full `spec`; `policy:{unit_name,task_scope,stop_grace_ms}`; `clock:{now,schedule}`; original `task_deadline_ms`; `preparation:{effort,observed_cli_version,executable_reference,prompt_bytes,policy_data}`; caller `environment` and `stdio`; injected `manager`, `qualification`, manager `source:{nextEvent}` and `read_timeout_ms`; and mandatory `artifact_fs:{lstat,realpath,open}`. No artifact I/O default is selected. The child vector is cloned from supplied data with the three accepted AGY environment names removed; host environment is neither read nor mutated. The prepared argv contains prompt data and must not be logged or persisted.

The constructor validates the JobSpec, creates one retained startup operation and preserves its once-derived deadline. Profile refusal marks NOT_ADMITTED, releases the startup reservation and leaves lifecycle SUBMITTED. `markDispatchAttempted()` records only a modeled event, never execution. `applyStartAck(ack,evidence)` requires the complete matching ACK and four independent affirmative admission/workspace/history/allocation booleans. It adopts the genuine retained operation without calling the manager start method. A late ACK after cancellation preserves canceled intent; no allocation is inferred before that explicit evidence. Schema/qualification assertions are caller data, not observed host proof.

`readManagerEvent()` drives only the existing manager route `source.nextEvent({binding,signal})`: native exit, cgroup observation or manager disconnect. `feedOutput(event)` drives only the collector route: byte chunks, EOF, raw wrapper observations and collector controls. Output cannot manufacture custody events. Conflicting independently observed manager/collector exit codes fence the task and raise the existing `observation_conflict` ContractError without selecting success or replacing the first native observation. Collector decode runs promptly when the complete output and raw wrapper exit become available. Raw allowlisted history can supply metrics after cancellation, but closed/faulted collection never promotes success.

`tick()` reconciles the original clock and source deadline driver. `abort()` latches task cancellation and calls the genuine owner's protected cancellation API before fallible callbacks; user abort and deadline alone set CANCELED. Clock/reentrancy/disconnect/collector failures remain operational failures. Capacity or internal faults can request guarded `session.settle()` without inventing user cancellation. `requestSettlement()` additionally permits active teardown for positively observed unsettled descendants after native exit. It never unconditionally stops nominal exit 0 or nonzero; passively observed emptiness remains CLEAN. Stop is at most once under the existing owner guards. Pending healthy native observations are not prematurely replaced with an invented unobserved exit merely to complete a record.

`finish(quiescence)` is caller-driven and asynchronous only because the verifier's explicit port is asynchronous. It rejects overlapping inspection. For exit zero, physical inspection requires accepted complete output, retained full-owned empty proof, and a closed caller assertion `{binding,task_scope,owned_writers_settled:true,exclusive_no_external_writers:true}` matching the exact epoch and scope. That assertion is a caller prerequisite; the verifier proves only stability observed during its read window. No ACK, hash or inode comparison independently proves quiescence or absence of external writers.

The original deadline and permanent cancellation latch guard the verifier before and after its awaits; the internal AbortSignal stops inspection once cancellation or fatal uncertainty is observed. Late witness/failure cannot replace CANCELED. After inspection, current evidence is reconciled before a synchronous lifecycle witness/settlement/record commit. Full cleanup observed as CLEAN remains CLEAN during clean cancellation; UNKNOWN/DIRTY_LEAK/fences block reuse. Nonzero native exit bypasses physical verification and remains FAILED. Provider status is passive; SUCCESS plus exit zero cannot deliver a missing artifact.

Final record construction preserves the raw integer/null exit, raw observed wall duration, backend UNKNOWN and inference UNKNOWN. Missing/null usage metrics map to wire UNKNOWN; observed zero remains zero. If the separate manager native-exit observation is absent, or raw wall duration is null or absent, no final record is emitted and `releaseWorkspace()` returns false. Provider elapsed duration and synthetic zero are never substitutes. A real observed wall value of zero is valid. Finalization passively closes the local collector to drop retained data; previous record/snapshot objects remain immutable.

`releaseWorkspace()` requires both a finalized record and genuine current cleanup proof, then delegates to the target owner's existing release guards. It does not weaken either reservation scope. Clean canceled tasks with valid records can release; cancellation alone is not a fabricated leak or permanent quarantine. `callerResult()` exposes the existing bounded known-custody response, which remains distinct from task settlement and retained ownership. Returning DEADLINE/FENCED/CANCELED does not itself authorize cleanup/release or establish a continuing native observation mechanism.
