# Read-only status and watch

`status` and `watch` read persisted evidence without Linear, Docker, Git, GitHub or Pi work. Status displays Contract digest, Implement/Verify profiles, candidate, terminal reason, Verify disposition, publication, pending external exact-head CI and unmerged disposition separately. Terminal publication success does not prove hosted CI or merge.

Exact run selectors distinguish history. Ticket selection rejects ambiguity. Schema-1 records are displayed by a separate bounded historical reader; they cannot be saved, claimed, resumed, promoted or executed. Multiple historical records require an exact run ID. Historical watch displays the snapshot and exits, rather than starting execution.

Reservation observation uses existing native/OS ownership evidence. Ambiguity is an owner investigation, not permission to delete locks or repair terminal state. `watch` exits on terminal state; its process exit is not the workflow verdict.
