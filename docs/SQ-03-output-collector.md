# SQ-03: injected AGY output collector

`createAgyOutputCollector(config)` creates a caller-driven in-memory observer. It exposes `applyEvent`, `drainAndDecode`, `snapshot` and passive `close`. It has no launcher, stream producer, async pump, timer, bus, signal or owner callback. `runtime_qualification` is always `NOT_ESTABLISHED_BY_SOURCE`. EOF means locally observed stream closure, never descendant settlement or released custody.

Configuration requires an exact job/unit/nonzero invocation binding, fixed limits `{max_stdout_bytes: 1048576, max_stderr_bytes: 65536}`, injected `{now}` clock and original positive safe integer task deadline. The optional decoder is synchronous; the default is the accepted AGY profile decoder. No clock is sampled during construction, snapshot or close.

Each event is a closed data object containing `type` and the exact binding. stdout/stderr chunks require Uint8Array and contiguous `stream_offset`; EOF requires the matching final offset. `stream_error` requires stdout/stderr plus a bounded abort-reason code; `abort` requires that code. `raw_exit` contains closed `{exit_code, signal, wall_ms}` observations. Tick and close have no extra fields. Malformed/foreign events return `BINDING_MISMATCH` without state changes or clock reads. Accessors, proxies and SharedArrayBuffer chunks are rejected without invoking their traps.

Stdout uses one private fixed arena. Incoming bounded stdout is defensively copied before external clock callbacks, then copied into the arena; no chunk queue is retained. Stderr content is discarded and only its validated length counted. Overflow records a saturated cap+1 lower bound, clears retained bytes and recommends owner abort as data. Zero retained bytes is not secure erase, immediate GC or host memory proof. Offsets cannot gap or replay; chunk-after-EOF faults. Duplicate matching EOF/raw exit is reported as `IDEMPOTENT_IGNORED` after active clock gating.

The first diagnostic stays sticky. Abort intent and first raw exit are captured before busy/clock guards, preserving cancellation reason and raw integer/null honestly. A conflicting raw exit cannot replace the first. Capacity faults recommend `CAPACITY_EXCEEDED`; other collector integrity faults recommend `STREAM_ERROR`; explicit abort/deadline recommendation preserves the first cancellation reason. These are advice to the external owner, never actions or proof of account/process state.

Both EOF observations produce IO_DRAINED; decoding additionally requires a raw exit, no cancellation/fault/close, and original deadline headroom. The collector attempts synchronous decoding at most once. It validates the complete positive metadata schema, accepts only OK or OK_WITH_FIELD_DIAGNOSTIC, copies/freezes the allowlisted metadata and drops retained stdout. PARSE_ERROR, exceptions, asynchronous/thenable returns, extra fields or invalid metadata fault closed. Wrapper values must match the independently captured observations; provider status cannot manufacture task success or cleanup. Memoized metadata remains available only while open and within deadline. The injected decoder must be synchronous. As a defensive invalid-return mitigation, ordinary native Promise rejections are observed using the intrinsic method without reading a then property, even after close/abort. Exotic Promise constructors/species are not invoked and their asynchronous side effects are not contained by this seam; they remain outside the synchronous decoder contract. No general async-lifetime guarantee is claimed.

Busy/revision checks surround every clock/decoder callback. Clock errors, regression and deadline expiry clear acceptance. Reentrant abort/raw exit retain protected observations before fault suppression. Reentrant close is terminal: callbacks returning later cannot add metadata, cancellation, diagnostics or recommendations. `close()` clears local retained data and current metadata without clock, owner or decoder calls. It does not stop tasks, discharge custody or release reservations. Snapshots are fresh frozen objects; prior returned records stay immutable.

The collector does not itself run while idle: actual scheduling, async producer/backpressure/drain, native capture, host owner lifetime, full descendant supervision, authentication, effective Credits Off and runtime admission remain unqualified. Native startup remains disabled; no benchmark readiness follows from synthetic tests.
