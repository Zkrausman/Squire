# SQ-03: pure provider metadata decoders

`decodeAgyJson(input)` and `decodeCodexJsonl(input)` decode bounded transient bytes into frozen, allowlisted metadata. They do not invoke a CLI, read configuration, verify subscriptions or Credits Off, select a model, control cancellation, emit JobRecords or qualify runtime execution. AGY one-shot JSON is the selected first source-only profile; invocation encoding waits for its independently reviewed version and byte-bound profile.

Both functions require a closed input with `raw_payload_bytes` (`Uint8Array`), explicit positive safe integer `max_response_bytes`, `wrapper_exit_code` (safe integer or null), `wrapper_signal` (a standard allowlisted signal name or null), and `wrapper_wall_ms` (nonnegative safe integer or null). Invalid boundary observations throw `ContractError` with code `INVALID_WRAPPER_OBSERVATION`. There is no default byte budget. Bytes are bounded before copying and decoded with fatal UTF-8 validation. The copy is transient, not a stable-capture or concurrent-writer custody claim.

AGY accepts exactly one JSON object. Codex accepts JSONL objects with exactly one `turn.completed` or `turn.failed`; standalone `error` is not a terminal. Every line must validate before metadata is returned. Duplicate keys, including escaped aliases and keys inside ignored fields, reject the entire payload. Duplicate terminals also reject. Structural failure returns `PARSE_ERROR`, null provider status and null usage, preserving only separately validated wrapper observations.

Usage fields map directly to `input`, `output`, `cache_read`, `thinking` and `total`. Present counters must be nonnegative safe integers: missing means unknown, explicit null or an invalid value receives a field diagnostic. Zero is preserved; values are never coerced or summed. AGY thinking and explicit total are preserved. Codex reasoning is separate `extra_metadata.codex_reasoning_output_tokens`; its thinking and total remain null. Backend model is always `UNKNOWN`. Requested model is not modified.

AGY `duration_seconds` is provider elapsed wall time, not inference time; missing is null, while invalid supplied duration uses the existing numeric-field diagnostic `INVALID_USAGE_COUNTER`. Unknown AGY status uses `OK_WITH_FIELD_DIAGNOSTIC` / `UNRECOGNIZED_STATUS` and retains valid counters. This diagnostic takes precedence when both status and numeric fields are invalid. Valid statuses are SUCCESS, ERROR, CANCELED, INTERRUPTED, INVALID, WAITING and RUNNING. Codex exposes only the two terminal tags.

Wrapper exit, signal and wall duration remain distinct from parser status, provider status and task outcome. `task_outcome_evaluated` is always false. EOF, provider cancellation and exit zero establish neither cancellation authority nor cleanup or correctness. Output contains no response, prompt, error text, conversation ID, tool arguments, unknown metadata or logs. This seam does not itself persist anything; callers must not persist raw input.

Implementation follows the independently reviewed SQ03 v3 contract (SHA-256 `84a3933fff933f9f4f83fa3667844bd4ce339f8becb63d76d01a42276c535487`) and shared independent review (`77af1d17b1f1dc8dbe4620839b1d7b583661c6d2dfb4511f7156e4f051892b0b`). Historical labels in those design artifacts remain unchanged. Synthetic tests demonstrate parsing logic only. CLI/schema/version admission, runtime entitlement, effective Credits Off, accounting, full descendant custody, host transport and benchmarking remain unqualified.
