# AIDEV-222 isolated Git workspace

AIDEV-222 owns a trusted TypeScript Git workspace for one run: a private bare repository at `/ticket/git/repo.git`, exactly one linked worktree at `/ticket/workspace`, and deterministic branch `squire/<ticket-id>-<run-id>`. The immutable Git workspace spec/manifests are a separate `urn:squire:git-workspace:v1:*` contract family; published normalized-ticket v1 remains unchanged.

`GitWorkspaceService` reuses the merged [trusted controller boundary](/concepts/trusted-controller-boundary.md) generic lease, preparation lease, terminal fence, and CAS surfaces rather than creating a duplicate lifecycle. Unknown Git child ownership, resource substitution, unsafe refs/config/alternates/submodules, or partial state fail closed. Production construction requires the runtime-authenticated `TrustedFilesystemIsolationAuthority` issued by the narrow AIDEV-223 composition boundary: its module-private token identity/WeakSet, pre-opened procfs/nsfs evidence descriptors, exact descriptor fstat identities, and exact canonical ticket-root, mount-namespace, root-identity, and mount-topology observation reject lookalikes, cross-root tokens, stale roots, nested mounts, descriptor errors/closure, malformed or overflowing evidence, and pathname bind-over substitution. The operation boundary reads live topology only from retained descriptors before service filesystem/Git/disposal side effects; explicit authority closure is idempotent and closed authorities fail closed. Node descriptor/st_dev checks remain defense in depth. The trusted controller and untrusted phase processes are separate security principals; AIDEV-223 owns namespace and identity provisioning. Approved HTTPS DNS addresses are bound to Git's libcurl `http.curloptResolve` entries while TLS hostname validation and redirects remain constrained. Offline status/commit are supported after independent readiness verification. Bundle export is single-feature-ref, descriptor/digest-bound, offline-verified, create-once, and host publication remains downstream. Disposal accepts an already-held terminal fence, is identity-checked and idempotent; retained bundle verification uses a disposal-owned scratch repository so workspace-first retention can be retried after controller restart. Its private journal includes exact child identities/digests and authenticated snapshots of the create-only contract bytes, so recovery does not trust mutable journal fields alone. It never completes global teardown or touches AIDEV-228 runtime/footer state.

Implementation is in `src/git/`; architecture details are in `docs/aidev-222-git-workspace.md`.
