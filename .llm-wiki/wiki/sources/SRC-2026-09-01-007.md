# AIDEV-215 Workflow Contracts — runtime policy revision

## Summary

The revised v1 contract documentation adds a `runtime-resolution` artifact for exact observed Pi and pi-llm-wiki versions, the Pi executable, and installation identities. The workflow config no longer requires an exact Pi version; its legacy optional field remains advisory for compatible v1 documents.

All immutable handoff, validation, transition, and current-head gate rules remain unchanged.

## Key Takeaways

- Runtime is resolved once and durably observed per run.
- All [five Pi sessions](/concepts/five-session-pi-rpc-topology.md) use that installation.
- [Fail-closed handoff validation](/concepts/immutable-handoff-validation.md) also validates runtime-resolution evidence through an explicit schema allowlist.
