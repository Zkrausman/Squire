# Docker Sandboxes Viability Spike

## Summary

The AIDEV-214 proof of concept validated one persistent ticket microVM, a private workspace and Docker engine, Pi RPC, exact JSONL resume, and five concurrent independent sessions. It established that direct host workspace modes do not meet Squire's isolation boundary.

The result supports a process-factory seam in AIDEV-216 while leaving the concrete Sandbox and Herdr adapters downstream. Exact session paths and controller-mediated export remain trust-critical. This replacement capture intentionally omits local host profile and temporary paths.

## Key Takeaways

- Five Pi roles can run concurrently with distinct process and session identities.
- Exact JSONL resume preserves one role's history.
- [Trusted controller mechanics](/concepts/trusted-controller-boundary.md) and [five-session topology](/concepts/five-session-pi-rpc-topology.md) are backed by executable feasibility evidence.
