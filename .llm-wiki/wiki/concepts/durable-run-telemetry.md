# Durable Run Telemetry

Current-run accounting captures only Implement and Verify invocations with controller-owned identity, duration and usage attribution. Private streams and zero-effect launch generations remain immutable evidence. Terminal candidate, Verify, reason, publication and external CI/merge are independent. Unknown is not zero. There is no historical backfill or usage parser expansion in AIDEV-316.

See [Contract → Implement → Verify](contract-implement-verify-workflow.md).
