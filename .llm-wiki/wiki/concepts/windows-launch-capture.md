# Windows Launch Capture

Windows private launch material, phase inputs, report evidence and logs use the native local-NTFS boundary. Protected DACLs, current-user/SYSTEM/Administrators principal checks, retained handles, no reparses, one-link files and bounded byte/identity verification remain mandatory. Unsafe existing objects are never repaired. Native read-only owner observation is distinct from mutation/creation authority. Node 24 Windows CI retains native launch/ACL/state-replacement/report-evidence coverage. New runs capture fixed core prompts, not custom prompt roots; removed supervisor transport is not reachable.

See [Contract → Implement → Verify](contract-implement-verify-workflow.md).

Host process exit/kill does not prove sandbox quiescence. Preserve a failed sandbox and candidate; never treat termination as permission to publish or rerun a phase.
