# Trusted Controller Boundary

The host controller owns ticket reservation, isolated exact-base workspace, fresh session identity, profile binding, clean candidate acceptance, raw private evidence and GitHub App publication. The model owns neither workflow transitions nor credentials. Implement alone writes; Verify is source-read-only and combines review with configured tests. Required hosted exact-head CI and owner merge remain independent authorities.

See [Contract → Implement → Verify](contract-implement-verify-workflow.md).
